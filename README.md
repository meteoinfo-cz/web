# 🌤️ MeteoInfo-CZ

Český meteorologický projekt o počasí. Tento web poskytuje dlouhodobé předpovědi počasí, indexy a aktuální meteorologické informace pro vybraná města v České republice.

🔗 **Navštivte web:** [https://meteoinfo-cz.github.io/web](https://meteoinfo-cz.github.io/web)

---

## 🚀 Hlavní funkce webu
* **Dlouhodobé předpovědi** – Výhledy počasí na několik dní dopředu.
* **Lokální informace** – Přesná data pro konkrétní města v ČR.
* **Meteorologické indexy** – Sledování specifických indexů a veličin.

## 🛠️ Použité technologie
* HTML5
* CSS3
* JavaScript
